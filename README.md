# 阴影贴图

纯标准库实现的深度图阴影渲染器：把场景三角形光栅化到光源正交深度图，
再对地板采样点做深度比较与 PCF 软阴影，输出深度可视化 PNG 并统计受光/阴影像素。

## 运行

```
python gen_samples.py
python -m shadow.cli data/scene.txt --size 256 --out depth.png
python -m pytest tests -q
```

`scene.txt` 是一块 4x4 地板和两块高度不同的挡板，光源从左上方照下来。地板被挡板遮住的部分
才是阴影区。`--size` 决定深度图边长（默认 256），`--softness` 决定阴影边缘过渡宽度
（PCF 半径，默认 2 像素）。

## 阴影判据

- 约定 `light_dir` 为光线传播方向（从光源指向场景），模长任意。
- 点的深度 = 点在光轴（forward）上的投影坐标，**值越小离光源越近**。
- 深度图逐像素保留所有覆盖该像素的三角形中的**最小深度**（最近遮挡物），
  三角形内部按重心坐标插值深度。
- 查询点 `p` 受光当且仅当 `depth(p) <= 深度图存储深度 + bias`，否则被遮挡。
  `shadow_factor` 返回周围 `(2*radius+1)^2` 次采样的受光比例，取值 [0, 1]。

## 自遮挡（条纹）处理

光栅化写入的是纹素中心处的三角形深度，而查询点一般不在纹素中心，同一表面
两者之间存在最多约半个纹素的深度差，直接比较会在自身表面产生条纹（shadow acne）。
做法：比较时加一个深度偏移 `bias = 4 * half / size`（约 2 个纹素的世界深度余量，
随深度图分辨率自适应）。该值远大于同表面纹素间深度差、远小于挡板高度（1 和 2），
因此自遮挡条纹被压到肉眼不可见，又不会让挡板阴影漏光。`bias` 也可通过
`shadow_factor(..., bias=...)` 显式指定。

## 边界采样

所有采样坐标（包括 PCF 核的每个偏移）都先钳制到 `[0, size-1]` 再读取，
越界采样按边界值处理，不会沿线性下标读到别的行，也不会抛越界异常。

## 软阴影边缘

`shadow_factor` 在投影点周围做 `(2*radius+1)^2` 次 PCF 采样取平均，
边缘从受光到阴影有平滑过渡而非硬台阶。过渡宽度由 `radius` 参数
（CLI 的 `--softness`）调节，默认 2。

## 光照方向一致性

`light_view` 对光轴做符号规范化（y、x、z 中第一个非零分量恒取负），
因此 `light_dir` 整体取反时视图基完全相同，深度符号不翻转、判定结果逐值一致；
`light_dir` 的模长也不影响结果（基向量均归一化）。光轴与默认 up 接近平行时
自动换用备用参考轴，基不会退化。

## 投影与输出

- 正交投影范围按场景在光轴垂直面内的包围盒自适应（含 5% 边距），
  参数存在 `DepthMap.center / DepthMap.half`，渲染与查询共用，保证一致。
- 深度可视化 PNG 尺寸与 `--size` 一致；输出只依赖场景与参数，
  连续运行两次逐字节相同。

## 统计（`python -m shadow.cli data/scene.txt --size 256 --out depth.png`）

在地板范围内按 256x256 网格采样，受光比例 >= 0.5 计为受光，否则计为阴影；
每块挡板单独渲染同投影的深度图，按硬判据统计其在地板上的投影面积
（地板 4x4，每个采样像素代表 (4/256)^2 = 0.000244 平方单位）：

| 指标 | 数值 |
| --- | --- |
| 受光像素 | 61563 |
| 阴影像素 | 3973 |
| 挡板 1（2x2，高 2）投影 | 3245 像素，0.7922 平方单位 |
| 挡板 2（1x1，高 1）投影 | 779 像素，0.1902 平方单位 |

两块挡板均竖直，光源方向 (0.3, -1, 0.2)，投影面积与几何推算
（挡板底边 x 光线水平偏移）一致。
