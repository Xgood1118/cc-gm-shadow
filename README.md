# 阴影贴图

骨架能算出光源基、能写深度图、能把它可视化成 PNG，但阴影判定不可用。

## 已知缺口

- `render_depth` 只把三角形的顶点打到深度图上，三角形内部的深度没有插值，
  遮挡关系在空洞处完全失效。
- 采样用最近邻，不做深度比较的方向判断，`shadow_factor` 拿点和深度对比时只判大小，
  没有处理自遮挡的偏移，实际渲染会大片漏光。
- 采样坐标不做边界钳制，越界时直接读 `data` 的线性下标，读到的是另一行的深度。
- 没有软阴影采样，边缘是硬台阶。
- 视图基的正方向没有与光源朝向对齐，`light_dir` 反向时深度正负号翻转。

## 运行

```
python gen_samples.py
python -m shadow.cli data/scene.txt --size 256 --out depth.png
python -m pytest tests -q
```

`scene.txt` 是一块 4x4 地板和两块高度不同的挡板，光源从左上方照下来。地板被挡板遮住的部分
才是阴影区。
