在现有 shadow 骨架上，把它做成一个能产出可用阴影的深度图渲染器。保留 Vec3、light_view、DepthMap、
render_depth、shadow_factor、save_depth_png、load_scene 的现有名字与签名，只用 Python 标准库，
不得引入第三方依赖，不得改动 data/scene.txt。

## 需要完成

1. **深度图填充**
   - 三角形内部要有深度，不能只写顶点。
   - 同一像素被多个三角形覆盖时保留离光源最近的那个。
   - 深度图尺寸由参数决定，默认 256。

2. **阴影判定**
   - 地板被挡板遮住的位置要判为阴影，没有被遮的判为受光，判据写进 README。
   - 自遮挡导致的条纹要压到肉眼不可见，做法写进 README。
   - 采样超出深度图范围时要按边界值处理，不能读到别的行的数据。

3. **边缘质量**
   - 阴影边缘不能是硬台阶，要有过渡。
   - 过渡宽度可调。

4. **光照方向**
   - 光源方向反向时深度正负号不能翻转，判定结果要保持一致。

5. **输出**
   - 深度图可视化 PNG 尺寸与 `--size` 一致，连续跑两次逐字节相同。
   - 受光区与阴影区的像素数量要能被脚本统计出来并写进 README。

6. **测试**
   - 覆盖：三角形内部有深度、最近深度胜出、越界采样不越界、夹角变化不影响判定、两次输出一致。
   - `python -m pytest tests -q` 全部通过。

完成后跑一遍 `python -m shadow.cli data/scene.txt --size 256 --out depth.png`，把受光像素数、阴影像素数
和两块挡板各自的投影面积贴进 README。
